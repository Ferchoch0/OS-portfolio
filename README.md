## 📂 Sobre este Repositorio (`portfolio-ottersolution`)

Este repositorio contiene el código fuente del sitio web del portafolio oficial de **Otter.ly**, construido utilizando **React** y **Vite**.

### 📋 Estructura del Proyecto

*   `src/data/`: Datos estructurados de la aplicación (equipo, servicios, proyectos, noticias). Permite actualizar contenidos fácilmente sin tocar código de componentes.
*   `src/sections/`: Secciones modulares de la Single Page Application (Hero, Servicios, Equipo, Portafolio, OtterNews, Contacto).
*   `src/components/`: Componentes UI atómicos y reutilizables.
*   `src/styles/` e `index.css`: Estilos globales y tokens del sistema de diseño (colores, fuentes, variables de espaciado).
